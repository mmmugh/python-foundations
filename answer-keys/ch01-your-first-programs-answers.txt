PYTHON FOUNDATIONS
Chapter 1 — Your First Programs

ANSWER KEY


VOCABULARY
──────────

 1. A ____ is a list of instructions written in an order a computer can
    follow.

      ANSWER: program

 2. The ____ function displays something on the screen; it is how a
    program tells you what it is doing.

      ANSWER: print()

 3. Text inside quotes, like "hello", is called a ____.

      ANSWER: string

 4. A line beginning with # is called a ____, and Python ignores it
    completely.

      ANSWER: comment


READING CODE
────────────

 5. What does this print?

        print("Hydrogen", "Helium", "Lithium")

      ANSWER: Hydrogen Helium Lithium

 6. What does this print?

        print(7)
        print(3 + 4)
        print("3 + 4")

      ANSWER: 7
          7
          3 + 4

 7. What does this print?

        # This line does nothing
        print("Done")

      ANSWER: Done

 8. What does this print?

        print("A")
        print("B", "C")
        print()
        print(2 * 3)
        print("2 * 3")

      ANSWER: A
          B C
          
          6
          2 * 3

 9. What does this print?

        print("Section 1")
        print()
        print("Section 2")

      ANSWER: Section 1
          
          Section 2


WRITING CODE
────────────

10. Complete this line so it prints the text 3 + 4 exactly, with no
    arithmetic performed: print(____)

      ANSWER: "3 + 4"

11. Complete this program so a blank line separates the two sections:
    print("Section 1") ____ print("Section 2")

      ANSWER: print()

12. Complete this line so it prints three items separated by single
    spaces: print("Hydrogen", ____, "Lithium")

      ANSWER: "Helium"


WHY IT WORKS
────────────

13. Python runs your instructions one line at a time, from ____ to ____,
    which is why swapping the order of two print() calls changes the order
    of the output.

      ANSWER: top
      ANSWER: bottom

14. Without quotes, 3 + 4 is ____ that Python works out and prints as 7;
    with quotes, "3 + 4" is ____ that Python prints exactly as written.

      ANSWER: a calculation
      ANSWER: a string

15. When Python cannot run a program, read the error message from ____ to
    ____: the last line names the problem, and the line above it points to
    where Python noticed.

      ANSWER: bottom
      ANSWER: top
