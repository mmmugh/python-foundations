PYTHON FOUNDATIONS
Chapter 2 — Variables and Types

ANSWER KEY


VOCABULARY
──────────

 1. A ____ is a name that refers to a value.

      ANSWER: variable

 2. Every value in Python has a ____, which determines what you can do
    with it.

      ANSWER: type

 3. Adding two strings together glues them end to end, an operation called
    ____.

      ANSWER: concatenation

 4. The text inside input() that asks the user a question, such as "What
    is your name? ", is called the ____.

      ANSWER: prompt

 5. Python's naming convention of lowercase words joined by underscores,
    as in final_score, is called ____.

      ANSWER: snake_case


READING CODE
────────────

 6. What does this print?

        count = 5
        count = count + 1
        print(count)

      ANSWER: 6

 7. What does this print?

        print(type(7))
        print(type(7.0))
        print(type("7"))
        print(type(True))

      ANSWER: <class 'int'>
          <class 'float'>
          <class 'str'>
          <class 'bool'>

 8. What does this print?

        print(7 + 7)
        print("7" + "7")

      ANSWER: 14
          77

 9. What does this print?

        a = 10
        b = a
        a = 99
        print(a, b)

      ANSWER: 99 10

10. What does this print?

        print(int(3.9))
        print(int("14"))

      ANSWER: 3
          14

11. Complete this line so the text typed by the user is converted to a
    whole number before arithmetic is done: age = ____(input('How old are
    you? '))

      ANSWER: int

12. Complete this program so the variable used on the last line exists:
    score = 42 ____ = "Ada" print(player, "scored", score)

      ANSWER: player

13. Complete this line so a temperature with a decimal point can be read
    without crashing: fahrenheit = ____(input("Temperature in degrees F:
    "))

      ANSWER: float

14. In a = 10; b = a; a = 99, the line b = a copies the value 10 into b at
    that moment; b does not stay linked to the name a. So after a = 99
    runs, printing b still shows ____.

      ANSWER: 10

15. Python fully evaluates the right side of = before doing anything else,
    so count = count + 1 first works out count's ____ value, adds 1, and
    only then points the name count at the ____ value.

      ANSWER: old
      ANSWER: new

16. print(age + 1) crashes with a TypeError when age comes from input(),
    because input() always returns a ____, even when the user types a
    number made only of digits.

      ANSWER: string
