ANSWER KEY


VOCABULARY
----------

 1. A ____ function is one that calls itself, on a smaller version of the
    problem each time, until it reaches a question it can answer straight
    away.

      ANSWER: recursive

 2. The ____ is a question small enough to answer straight away, with no
    more calls.

      ANSWER: base case

 3. The ____ calls the function again on a smaller question, and builds
    its answer from the smaller call's answer.

      ANSWER: recursive case

 4. A table that follows recursion one call at a time, with what each call
    waits for and what it gives back, is a ____.

      ANSWER: call table

 5. Remembering answers already worked out, in a dictionary, so each one
    is worked out only once, is called ____.

      ANSWER: memoization

 6. Something that must be true before a function is called, like "the
    list is sorted by id", is the function's ____.

      ANSWER: precondition

11. What does this print?

        def factorial_traced(n, depth=0):
            indent = "  " * depth
            print(f"{indent}factorial({n}) called")
        
            if n <= 1:
                print(f"{indent}base case, giving back 1")
                return 1
        
            result = n * factorial_traced(n - 1, depth + 1)
            print(f"{indent}giving back {n} * factorial({n - 1}) = {result}")
            return result
        
        
        factorial_traced(2)

      ANSWER: factorial(2) called
            factorial(1) called
            base case, giving back 1
          giving back 2 * factorial(1) = 2
