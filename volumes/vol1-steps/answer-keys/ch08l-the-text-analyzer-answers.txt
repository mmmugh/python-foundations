ANSWER KEY


VOCABULARY
----------

 1. A string is a ____ of characters, so `len()`, indexing and slicing
    work on it much as they do on a list.

      ANSWER: sequence

 2. Unlike a list, a string is ____: it cannot be changed after it is
    made, so every string method gives back a new string instead.

      ANSWER: immutable

 3. The ____ operator asks whether one string appears inside another, as
    in `"quick" in sentence`.

      ANSWER: in

 4. `\n` and `\t`, which stand for characters you can't type straight into
    a string, are called ____ sequences.

      ANSWER: escape

 5. A word that reads the same forward and backward, like racecar, is a
    ____.

      ANSWER: palindrome
