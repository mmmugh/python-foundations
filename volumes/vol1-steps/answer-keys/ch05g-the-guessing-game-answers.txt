PYTHON FOUNDATIONS
Unit 5 - Repetition

ANSWER KEY


VOCABULARY
----------

 1. A loop that repeats as long as its condition stays true is called a
    ____ loop.

      ANSWER: while

 2. A loop whose condition never becomes false, so it repeats forever, is
    called an ____ loop.

      ANSWER: infinite

 3. A loop inside another loop is called a ____ loop.

      ANSWER: nested

 4. The pattern of setting up a variable before a loop and updating it on
    every pass - to build a sum, a count, or a string - is called the ____
    pattern.

      ANSWER: accumulator

 5. A value that means "that's all", such as `stop` or `0`, and ends a
    loop that reads input, is called a ____ value.

      ANSWER: stop

 6. A `True` or `False` variable used to record how a loop ended, such as
    whether the player won or ran out of guesses, is called a ____.

      ANSWER: flag


READING CODE
------------

 7. What does this print?

        count = 1
        
        while count <= 5:
            print(f"Count is {count}")
            count += 1
        
        print("Done.")

      ANSWER: Count is 1
          Count is 2
          Count is 3
          Count is 4
          Count is 5
          Done.

 8. What does this print?

        for i in range(2, 6):
            print(i)

      ANSWER: 2
          3
          4
          5

 9. What does this print?

        for table in range(1, 3):
            for multiplier in range(1, 3):
                print(f"{table} x {multiplier} = {table * multiplier}")

      ANSWER: 1 x 1 = 1
          1 x 2 = 2
          2 x 1 = 2
          2 x 2 = 4

10. What does this print?

        for number in range(1, 11):
            if number % 3 != 0:
                continue
            print(number)

      ANSWER: 3
          6
          9

11. What does this print?

        total = 0
        for i in range(1, 6):
            if i == 3:
                continue
            total += i
        print(total)

      ANSWER: 12

12. This loop makes three passes. Which lines get a row in its trace
    table, in order? Lines

        count = 1
        while count <= 3:
            count += 1

      ANSWER: 1, 2, 3, 2, 3, 2, 3, 2

13. Fill in the blank, so the loop reads the next word before it asks

        while word != "stop":
            print(f"You typed {word}.")
            word = ____("Word (or stop): ")

14. Fill in the blank:

        for i in ____(5, 0, -1):
            print(i)

      ANSWER: range

15. Fill in the blank:

        count = 1
        while count <= 5:
            print(f"Count is {count}")
            count ____ 1
        print("Done.")

      ANSWER: +=

16. Fill in the blank:

        while True:
            command = input("Enter a command (or 'quit'): ")
            if command == "quit":
                ____
            print(f"You said: {command}")

      ANSWER: break


WHY IT WORKS
------------

17. A `while` loop needs a variable set up before the loop, a condition
    that can become false, and something inside the loop that moves toward
    that. Deleting `count += 1` means `count` never changes, so `count <=
    5` stays ____ forever and the loop never ends.

      ANSWER: true

18. `range(n)` always produces exactly ____ values, which is why
    `range(5)` produces `0` through `4` rather than `0` through `5`.

      ANSWER: n

19. Starting `largest` at `0` before the loop gives the wrong answer when
    every number entered is ____, because none of them would ever be
    greater than `0`.

      ANSWER: negative
