## Extra practice: a secret code

This page is optional: one more project for unit 8, if you want it. Nothing later needs it.

A Caesar shift is one of the oldest secret codes. Every letter moves the same number of places along the alphabet: with a shift of 3, `a` becomes `d`, `b` becomes `e`, and `Hello` becomes `Khoor`. Shift back by 3, and the message comes out again. You can already find where a character is in a string, pick out the character at an index, work out what is left over with `%`, and build new text one character at a time. By the end of this page you will have a code machine that turns a message into code, and back.

Each step names its function exactly. That name is what the check calls, so spell it as written; everything inside is up to you.

### Steps

1. Write `shift_letter(letter, shift)`, which gives back the small letter `shift` places further along the alphabet. So `shift_letter("a", 3)` gives back `"d"`, and a shift of 0 gives back the letter itself. For now, no shift goes past `z`.

> The alphabet can be a string, `"abcdefghijklmnopqrstuvwxyz"`. Which method from lesson 8.4 says where a letter is in it? And once you have a position, how do you get the letter there (lesson 8.1)?

2. Now let a shift go past `z`, and start again at `a`, the way a clock's hand comes round to the top again. So `shift_letter("x", 3)` gives back `"a"`, and `shift_letter("z", 1)` gives back `"a"` too. A shift of 26 goes all the way round, back to the letter itself.

> The positions run from 0 to 25. What is left over when the new position is divided by 26? Lesson 3.1's `%` gives what is left over.

3. A message has more than letters in it. Make `shift_letter()` give back a space, a sign like `!`, or a digit as it was. So `shift_letter("!", 3)` gives back `"!"`.

> What does `find()` give back for a character that is not in the alphabet?

4. Capitals stay capitals: `shift_letter("A", 3)` gives back `"D"`, and `shift_letter("Z", 1)` gives back `"A"`.

> `find()` finds no capitals in a string of small letters. Could there be a second alphabet, in capitals, for it to look in? Or could the letter be made small first (lesson 8.2), and the answer made a capital again?

5. Write `encode(text, shift)`, which gives back the whole of `text` with every letter shifted and everything else left as it was. So `encode("Hello, World!", 3)` gives back `"Khoor, Zruog!"`. Copy your `shift_letter()` into this box first.

> Lesson 8.9 built new text one character at a time. What goes in for each character?

6. Write `decode(text, shift)`, which gives back the message that `encode(text, shift)` was made from. So `decode("Khoor, Zruog!", 3)` gives back `"Hello, World!"`, and `decode("abc", 3)` goes back past `a` to give `"xyz"`. Copy your `shift_letter()` and `encode()` into this box first.

> Which shift undoes a shift of 3? Before you change anything, try `shift_letter("a", -1)`. Does your `%` already go round the other way? `-1 % 26` is worth a look.

7. Put the code machine together. Ask `Encode or decode?`, then the message, then the shift, a whole number. The first answer may come in any capitals, with spaces at its ends. Print the result as `Result: Khoor, Zruog!`. If the first answer is neither encode nor decode, print `Please type encode or decode.` and ask nothing more. Copy your functions into this box first.

> Say it: what goes in, and what comes out? ([How to start a problem](99-how-to-start-a-problem.html))
> Split it: ask the first question, and tidy the answer; if it is encode, ask for the message and the shift, and print the encoded result; if it is decode, do the same with the decoded result; otherwise, print the message about typing encode or decode.
> Name it: the functions are named for you. What would you call the three answers?
> Check it: try encode, `Hello, World!` and 3, then decode `Khoor, Zruog!` with 3. Then the awkward ones: `DECODE` in capitals; a shift of 0; a message with no letters at all, like `2 + 2 = 4`; an empty message; and `shout`, which is neither.
