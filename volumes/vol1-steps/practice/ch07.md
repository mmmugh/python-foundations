## Extra practice: a playlist manager

This page is optional: one more project for unit 7, if you want it. Nothing later needs it.

A playlist is a list of song titles, in the order they play. The song at index 0 is the one playing now. You can already add an item to a list, put one in anywhere, take one out, slice a list, sort it, and find where an item is. By the end of this page you will have a playlist manager: a handful of functions, and a program that uses them.

Each step names its function exactly. That name is what the check calls, so spell it as written. Where a step gives you lines that call your function, write the function above them and keep them. Their last line prints the playlist itself, to show that your function left it as it was.

### Steps

1. Write `with_song(playlist, title)`, which gives back a new list: the playlist with `title` added at the end. The playlist itself stays as it was.

```python
playlist = ["Ghost Town", "Ribbons", "Anvil"]
print(with_song(playlist, "Low Tide"))
print(with_song([], "Low Tide"))
print(playlist)
```

> The last line should still print three songs. How did lesson 7.3 make a second list of your own, so that changing it leaves the first one alone?

2. Write `play_next(playlist, title)`, which gives back a new list with `title` put in second, straight after the song that is playing now. The playlist itself stays as it was.

```python
playlist = ["Ghost Town", "Ribbons", "Anvil"]
print(play_next(playlist, "Low Tide"))
print(play_next([], "Low Tide"))
print(playlist)
```

> Which index is the second place? Lesson 7.4 put an item in at any index you choose.

3. Write `without_song(playlist, title)`, which gives back a new list with the first copy of `title` taken out. If the song is not in the playlist, the new list has the same songs. The playlist itself stays as it was.

```python
playlist = ["Ghost Town", "Ribbons", "Anvil", "Ribbons"]
print(without_song(playlist, "Ribbons"))
print(without_song(playlist, "Low Tide"))
print(without_song([], "Low Tide"))
print(playlist)
```

> What does `remove()` do with a song that is not there? Which method from lesson 7.9 says how many times a song is in the list?

4. Write `up_next(playlist)`, which gives back a list of the next three songs, after the one that is playing now. A playlist with fewer songs after it gives back as many as it has.

> Which index does the next song have, and where does a slice of three from there stop? Can a slice ever be out of range (lesson 7.2)?

5. Write `song_number(playlist, title)`, which gives back where `title` is in the playlist, counted the way people count: the first song is number 1. If the song is there twice, give back the number of the first one. If it is not there at all, give back 0.

> `index()` from lesson 7.9 counts from 0. What does it do with a song that is not there? Try it, then think of step 3.

6. Write `a_to_z(playlist)`, which gives back a new list of the songs in alphabetical order. The playlist itself stays in its playing order.

```python
playlist = ["Ribbons", "Anvil", "Low Tide", "Ghost Town"]
print(a_to_z(playlist))
print(a_to_z([]))
print(playlist)
```

> Lesson 7.6 has two ways to sort. Which one leaves the old list alone?

7. Write `show(playlist)`, which prints the playlist, one song per line, numbered from 1, like `1. Ghost Town`. It gives back nothing. An empty playlist prints nothing at all.

```python
show(["Ghost Town", "Ribbons", "Anvil"])
show([])
```

> Lesson 7.7 numbered a list of names. How did it turn index 0 into the 1 people expect?
