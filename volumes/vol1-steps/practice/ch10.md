## Extra practice: a bus timetable

This page is optional: one more project for unit 10, if you want it. Nothing later needs it.

A bus station keeps each service as a tuple of three parts: its route, the minute it leaves, and where it goes, like `("47", 415, "Harbor")`. The minute is counted from midnight, so 415 is 6:55 in the morning: minutes are easy to compare and sort, and a clock face is only for showing. Here are some services:

| Route | Leaves | To |
| --- | --- | --- |
| 12 | 380 (6:20) | Museum |
| 47 | 415 (6:55) | Harbor |
| 47 | 500 (8:20) | Harbor |
| 9 | 1000 (16:40) | Airport |

You can already give back two values from a function, unpack a tuple into names, sort a list by a key, and group things into a dictionary of lists. By the end of this page you will have the station's timetable: a handful of functions, and a program that uses them.

Each step names its function exactly. That name is what the check calls, so spell it as written. Where a step gives you lines that call your function, write the function above them and keep them. Where their last line prints the services, it is to show that your function left them as they were. When a step uses a function from an earlier step, copy that one into the box too.

### Steps

1. Write `clock_parts(minute)`, which gives back two values: the hour, and the minutes past the hour. So `clock_parts(415)` gives back 6 and 55.

```python
hour, past = clock_parts(415)
print(hour, past)
print(clock_parts(1000))
print(clock_parts(0))
```

> There are 60 minutes in an hour. How did `split_time()` in lesson 10.2 give back two values at once?

2. Write `clock(minute)`, which gives back the time as text: the hour, a colon, then the minutes past the hour as two digits. So `clock(415)` gives back `"6:55"`, `clock(605)` gives back `"10:05"`, and `clock(0)`, midnight, gives back `"0:00"`.

> Use `clock_parts()`. What comes out for 605 if you put the minutes in as they are? Which one-line way to choose between two values, from lesson 10.7, could put a 0 in front only when the minutes are under 10?

3. Write `describe(service)`, which gives back one service as a line of text, like `"47 at 6:55 to Harbor"`. Unpack the service into three names first, so each part has a name that says what it is.

```python
print(describe(("47", 415, "Harbor")))
print(describe(("12", 605, "Museum")))
print(describe(("N1", 0, "Depot")))
```

> How did lesson 10.3's loop over the cities give each part of a tuple its own name? The same line works outside a loop, as in lesson 10.1.

4. Write `by_time(services)`, which gives back a new list of the services in the order they leave, earliest first. The list itself stays as it was.

```python
services = [("47", 500, "Harbor"), ("12", 380, "Museum"), ("9", 300, "Airport"), ("47", 415, "Harbor")]
print(by_time(services))
print(by_time([]))
print(services)
```

> Lesson 10.5 told `sorted()` which field to sort by, with `key=`. Which part of a service is the minute it leaves, and how do you reach it (lesson 10.1)? Which of lesson 7.6's two ways to sort leaves the old list alone?

5. Write `by_route(services)`, which gives back a dictionary from each route to a list of its departure times, as text from `clock()`, in the order the services are in the list. So for the four services in the table, route `"47"` has `["6:55", "8:20"]`.

> It is lesson 10.6's grouping loop. What is the key here, and what goes into each list?

6. Put the timetable together. Start from the services below, which are in no order. Print the timetable: every service in the order they leave, one line each, like `12 at 6:20 to Museum`. Then ask for a route. If any bus runs on it, print its departure times in the order they leave, joined with `", "`, as `Route 47: 6:55, 8:20`. If none does, print `No buses on route 5`, with the route that was typed. Copy your functions into this box first.

```python
services = [
    ("47", 500, "Harbor"),
    ("12", 380, "Museum"),
    ("9", 1000, "Airport"),
    ("47", 415, "Harbor"),
    ("12", 605, "Museum"),
]
```

> Say it: the services are there already, and a route goes in; what comes out, and in what order? ([How to start a problem](99-how-to-start-a-problem.html))
> Split it: the functions are built already, so the plan is the program: put the services in time order, and keep that list; print a line for each one; group that list by route; ask for the route; then the groups decide the last line.
> Name it: the functions are named for you. What would you call the services in time order, the groups, and the route that was typed?
> Check it: try 47: five lines of timetable, from `12 at 6:20 to Museum` to `9 at 16:40 to Airport`, then `Route 47: 6:55, 8:20`. Then 12, whose times are 6:20 and 10:05, in that order. Which list did you group: the one in time order, or the one you started from? Then the awkward ones: route 9, which has one bus, and route 5, which has none.
