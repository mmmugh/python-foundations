## Extra practice: a unit converter toolkit

This page is optional: one more project for unit 6, if you want it. Nothing later needs it.

The recipe book is American, the oven dial is in Fahrenheit, and the running app is in kilometers, so the same sums come up again and again. You can already write a function, give back a value with `return`, round it, and call one function from inside another. By the end of this page you will have a toolkit of conversions, each written once, and a program that uses them.

| From | To | How |
| --- | --- | --- |
| Celsius | Fahrenheit | multiply by 9, divide by 5, then add 32 |
| Kilometers | miles | multiply by 0.621371 |
| Cups | milliliters | multiply by 236.588 |

Each step names its function exactly. That name is what the check calls, so spell it as written; everything inside is up to you.

### Steps

1. Write `c_to_f(celsius)`, which gives back the temperature in Fahrenheit, rounded to 1 decimal place.

> Check it against the two you know: 100 is 212.0, and 0 is 32.0. Then a fever, 39.2, which is 102.6 once it is rounded.

2. Write `f_to_c(fahrenheit)`, which goes the other way, also rounded to 1 decimal place. Take away 32 first, then multiply by 5 and divide by 9.

> Try 212 and 32. Then the awkward one: 0 Fahrenheit is below 0 Celsius.

3. Write `km_to_miles(km)`, rounded to 2 decimal places.
4. Write `cups_to_ml(cups)`, rounded to 1 decimal place.
5. Oven dials only go up in 25s. Write `oven_setting(celsius)`, which converts to Fahrenheit and gives back the nearest 25: 180 becomes 356.0, so the dial says 350. Call `c_to_f()` instead of repeating its sum. Copy your `c_to_f()` into this box first.

> How many 25s are there in 356.0? Round that, then multiply by 25 again.

6. Recipes give their times in minutes. Write `hours_in(minutes)`, which gives back how many whole hours there are in that many minutes: 125 minutes has 2.

> It is how many whole, how many left, from lesson 3.1, with 60 minutes in an hour.

7. Write `minutes_left(minutes)`, which gives back the minutes left over after the whole hours: 125 minutes leaves 5.
8. Put the toolkit to work. Ask for a temperature in °C, a distance in km, a number of cups and a cooking time in minutes, in that order. Each one can have a decimal point, except the minutes. Then print five lines like these, using your functions: `180 C is 356.0 F`, `Oven dial: 350`, `5 km is 3.11 miles`, `2 cups is 473.2 ml` and `125 minutes is 2 h 5 min`. Copy your functions into this box first.

> Say it: four answers go in; which five lines come out? ([How to start a problem](99-how-to-start-a-problem.html))
> Split it: the functions are built already, so the plan is the program: ask the four questions; print the temperature line and the dial line; print the distance line; print the cups line; print the time line. A `main()` that does this, called on the last line, keeps the plan in one place.
> Name it: the functions are named for you. What would you call the four answers?
> Check it: try 180, 5, 2 and 125, which give the lines above. Then the awkward ones: 0 for everything, which gives 32.0 F and a dial of 25; a temperature below 0, like -10; and 59 minutes, which is 0 h 59 min.
