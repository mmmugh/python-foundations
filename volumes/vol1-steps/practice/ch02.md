## Extra practice: a hiking trip planner

This page is optional: one more project for unit 2, if you want it. Nothing later needs it.

The Kettle Ridge trail is 12.4 km long. Everyone who plans a day on it does the same sums: how long it takes, how much water to carry, and what the permits cost. You can already store values in variables, ask the user a question, and turn the answer into a number. By the end of this page you will have a planner that works out the whole day from three answers.

The planner works from these numbers:

| What | Value |
| --- | --- |
| Trail length | 12.4 km |
| Water | 0.75 liters for each hour of walking |
| Permit | 4.50 for each person |

Walking pace is different for everyone, so the planner asks for it, in minutes per km. A steady walker takes about 11.

### Steps

1. Store the trail's name, `Kettle Ridge`, and its length, `12.4`, in two variables. Then print `Kettle Ridge is 12.4 km` from them, with commas between the pieces.
2. Ask for a walking pace in minutes per km, and print how many minutes the trail takes. A pace can have a decimal point, like 10.5, so choose the right way to turn it into a number.
3. Minutes are hard to picture. On the next line, print the time in hours as well. Copy your program so far into this box first.
4. Print how many liters of water one person needs: 0.75 for each hour of walking. Copy your program so far into this box first.

> Is it 0.75 for each hour, or for each minute? Which of your variables is in hours?

5. After the pace, ask how many people are going, and print the water the whole group needs. Copy your program so far into this box first.
6. Add a last line: what the permits cost, at 4.50 for each person. Copy your program so far into this box first.
7. Put the planner together. Ask for the trail length, then the pace, then how many people. Print the length, the time in minutes, the time in hours, the water for one person, the water for the group, and the permits, in that order.

> Say it: three answers go in; what comes out? ([How to start a problem](99-how-to-start-a-problem.html))
> Split it: ask the three questions, turning each answer into a number; work out the minutes, the hours and the water; print each line.
> Name it: a name for each value that says what it is, such as `distance_km`. You have chosen most of them already.
> Check it: try 12.4, 11 and 4: is it 136.4 minutes and 18.0 for the permits? Then an awkward group: 0 people. Does every line still make sense?
