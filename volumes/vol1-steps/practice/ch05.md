## Extra practice: a savings goal tracker

This page is optional: one more project for unit 5, if you want it. Nothing later needs it.

The bike costs **240**. You put money aside every week, and you want to know which week you will have enough. You can already repeat lines with `for` and `while`, add up as you go, read values until a stop value, and leave a loop early with `break`. By the end of this page you will have a tracker that adds up each week's savings and says when the bike is yours.

Every amount is a whole number. Each step names the exact lines it prints.

### Steps

1. Print `Week 1` to `Week 8`, one per line, with a `for` loop.
2. Ask how much you save each week. Then print the total so far at the end of each of the 8 weeks, like `Week 1: 15`, then `Week 2: 30`, and so on.

> One total, set up before the loop and added to in the block.

3. Every 4th week, in weeks 4 and 8, you also get a bonus of 10, on top of the usual amount. Print the same 8 lines, with the bonus counted. Copy your step 2 into this box first.

> Weeks 4 and 8 are the weeks that 4 goes into with nothing left over.

4. A new program. Ask how much you have saved already, then how much you save each week, which is more than 0. Print how many weeks it takes to reach 240, like `Weeks: 16`. Reaching exactly 240 counts. If you have 240 already, it takes `Weeks: 0`.

> Can you know how many weeks it takes before the loop starts? Which loop did lesson 5.6 say to use when you can't know, and what should its condition ask about the total?

5. Real weeks are not all the same. A new program: ask for each week's savings until 0 is typed, which means there are no more. After each week, print the total so far, like `Saved: 45`. After the 0, print how many weeks there were, like `Weeks: 3`.

> Read, loop, read again, as in lesson 5.6. Is the 0 a week?

6. Now the bike. Stop as soon as the total reaches 240, print `Goal reached in week 3!` (with the right week), and ask nothing more. If the 0 comes first, print `Still to save: 90` (with what is still needed). These two lines take the place of the `Weeks:` line. Copy your step 5 into this box first.

> How did lesson 5.6 leave a loop the moment something happened? And after the loop, how did lesson 5.7's game with 5 guesses know which way it had ended?

7. Put the tracker together. First ask how much you have saved already. If that is 240 or more, print `Goal reached already!` and ask nothing more. Otherwise, ask for each week's savings as in step 6, print the `Saved:` line after each, counting what you had already, and end with the goal line or the still-to-save line.

> Say it: what you have already goes in, then a week's savings at a time; what comes out? ([How to start a problem](99-how-to-start-a-problem.html))
> Split it: ask what is saved already; if it is 240 or more, say so; otherwise, loop: read a week's savings, stop at a 0, add it, count the week, print the total, and stop at the goal; after the loop, the goal line or the still-to-save line.
> Name it: the total, the week and a week's savings each need a name. You have chosen them already.
> Check it: try 100, then 50, 50 and 50: the goal comes in week 3. Then the awkward ones: 240 already, which asks nothing more; 0 already, then a 0 straight away; and savings that land on exactly 240.
