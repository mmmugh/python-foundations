## Extra practice: the Tower of Hanoi

This page is optional: one more project for unit 12, if you want it. Nothing later needs it.

The Tower of Hanoi is an old puzzle. There are three pegs, A, B and C. On peg A sits a pile of discs, each one smaller than the disc below it; disc 1 is the smallest, at the top. The puzzle is to move the whole pile to peg C, one disc at a time, and never to put a bigger disc on top of a smaller one. Peg B is the spare: a place to put discs on the way.

You can already write a function that calls itself, follow its calls in a call table, and give back an answer built from a smaller one. By the end of this page you will have a program that prints every move of the puzzle, for as many discs as you ask for, and says how many moves it took. It starts with one warm-up on a number.

Each step names its function exactly. That name is what the check calls, so spell it as written. Where a step gives you lines that call your function, write the function above them and keep them. When a step uses a function from an earlier step, copy that one into the box too.

### Steps

1. Write a recursive function `digit_sum(n)` that gives back the sum of the digits of the whole number `n`, which is 0 or more. So `digit_sum(1234)` gives back 1 + 2 + 3 + 4, which is 10, and `digit_sum(0)` gives back 0.

> Try `print(1234 % 10)` and `print(1234 // 10)`. Which one is the last digit, and which is a smaller question of the same kind? Which number has no digits left to add?

2. Write `move_two(start, end, spare)`, which prints the three moves that take a pile of two discs from the peg `start` to the peg `end`: disc 1 out of the way onto the `spare` peg, disc 2 to the `end` peg, then disc 1 from the spare peg on top of it. Print each move like `Move disc 1 from A to B`. It gives back nothing.

```python
move_two("A", "C", "B")
print("--")
move_two("A", "B", "C")
```

> The second call hands in the pegs in a different order. Which parameter holds the peg a disc leaves, and which the peg it goes to?

3. Write `move_three(start, end, spare)`, which prints the seven moves for a pile of three discs. Use `move_two()`: move the top two discs out of the way onto the spare peg, move disc 3 to the end peg, then move the two discs from the spare peg on top of it.

```python
move_three("A", "C", "B")
```

> When the two discs go out of the way, which peg is their end, and which is their spare? And when they come back?

4. Look at `move_two()` again: disc 1 out of the way, disc 2 across, disc 1 back on top. That is `move_three()`'s shape, with a pile of one in place of a pile of two. So every pile has the same shape: the top `n - 1` discs out of the way, disc `n` to the end peg, then the `n - 1` discs back on top. Write a recursive function `hanoi(n, start, end, spare)` that prints the moves for a pile of `n` discs. With 0 discs there is nothing to move, so it prints nothing.

```python
hanoi(1, "A", "C", "B")
print("--")
hanoi(2, "A", "C", "B")
print("--")
hanoi(3, "A", "C", "B")
print("--")
hanoi(0, "A", "C", "B")
print("--")
```

> What is the base case: the pile with nothing to move? An `if` needs no `else`. Then, which two calls does the recursive case make, and with the pegs in which places? Step 3 says.
> Did it call itself? While you try it, add `print("called with", n, start, end, spare)` as the first line inside the function: each pile asks for two smaller ones. Take the print out before you press Check.

5. Write a recursive function `moves(n)` that gives back how many moves `hanoi()` makes for a pile of `n` discs, without printing them. Count the way `hanoi()` works: the moves for `n - 1` discs, one move for disc `n`, then the moves for `n - 1` discs again. A pile of 0 discs takes 0 moves.

> It is `hanoi()`'s shape, giving back a number instead of printing. What does the base case give back? Check it against steps 2 and 3: 3 moves for two discs, and 7 for three.

6. Put the puzzle together. Ask how many discs are on peg A. Print every move that takes them to peg C, with peg B as the spare. Then print how many moves that took, as `Moves needed: 7`. Copy your functions into this box first.

> Say it: a number of discs goes in; what comes out, and in what order? ([How to start a problem](99-how-to-start-a-problem.html))
> Split it: the functions are built already, so the plan is the program: ask for the number of discs; print the moves, with each peg in its place; then print the count.
> Name it: the functions and their parameters are named for you. What would you call the number of discs?
> Check it: try 2: three moves, then `Moves needed: 3`. Then 3, and 1. Then the awkward one: 0 discs, which prints no moves at all, then `Moves needed: 0`. If it stops with a RecursionError, which base case do the calls go past (lesson 12.4)? Bigger piles work too, but 10 discs take 1,023 moves, so keep to small ones.
