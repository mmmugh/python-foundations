## Extra practice: a lost property register

This page is optional: one more project for unit 9, if you want it. Nothing later needs it.

The station's lost property office gives everything handed in a ticket, like `A1`, and writes down what kind of thing it is and where it was found:

| Ticket | Kind | Place |
| --- | --- | --- |
| A1 | umbrella | platform 2 |
| A2 | phone | ticket hall |
| A3 | umbrella | cafe |

The register is a dictionary of tickets, and each ticket's value is a dictionary of its own, as in lesson 9.6: `{"A1": {"kind": "umbrella", "place": "platform 2"}, ...}`. You can already look a key up safely, copy a dictionary, count things into one, and keep each item once in a set. By the end of this page you will have the program behind the office's counter.

Each step names its function exactly. That name is what the check calls, so spell it as written. Where a step gives you lines that call your function, write the function above them and keep them. Their last line prints the register itself, to show that your function left it as it was.

### Steps

1. Write `kind_of(register, ticket)`, which gives back the kind of the item with that ticket, like `"umbrella"`, or `None` if there is no such ticket.

> How did lesson 9.2 ask whether a key is there before looking it up? Then, how do you reach one level down (lesson 9.6)?

2. Write `with_item(register, ticket, kind, place)`, which gives back a new register with one more item in it: a `kind` found at `place`, under the new `ticket`. The register itself stays as it was.

```python
register = {"A1": {"kind": "umbrella", "place": "platform 2"}}
bigger = with_item(register, "A2", "phone", "ticket hall")
print(bigger["A2"]["kind"], "found at", bigger["A2"]["place"])
print(len(bigger), "items")
first = with_item({}, "A1", "scarf", "cafe")
print(first["A1"]["kind"], "found at", first["A1"]["place"])
print(register)
```

> How did lesson 9.7 make a dictionary of your own? And what goes in under the new ticket?

3. When the owner comes to collect, the item's ticket comes out. Write `claimed(register, ticket)`, which gives back a new register without that ticket. If there is no such ticket, the new register has the same items. The register itself stays as it was.

```python
register = {
    "A1": {"kind": "umbrella", "place": "platform 2"},
    "A2": {"kind": "phone", "place": "ticket hall"},
}
print(sorted(claimed(register, "A1")))
print(sorted(claimed(register, "A9")))
print(sorted(claimed({}, "A1")))
print(sorted(register))
```

> What does `del` do with a key that is not there? What did lesson 9.2 ask first?

4. Write `count_kinds(register)`, which gives back a dictionary of how many items of each kind the register holds. For the table above, that is `{"umbrella": 2, "phone": 1}`.

> It is the counting pattern of lesson 9.4. What does it count here: the tickets, or each ticket's kind?

5. Write `places(register)`, which gives back a list of the places where things were found, each place once, in alphabetical order. For the table above, that is `["cafe", "platform 2", "ticket hall"]`.

> Which container keeps each item once (lesson 9.8)? And which function gives back its items in order?

6. Put the counter together. Start from the register below. A new item is handed in: ask what kind of thing it is, then where it was found, and add it under the ticket `A5`. Then someone comes to collect: ask for their ticket. If the register has it, print `Claimed: phone, found at ticket hall`, with that item's kind and place, and take it out. If not, print `No item with ticket A9`, with the ticket that was typed. Then print how many of each kind are still held, one line each, in the order each kind first appears in the register, like `umbrella: 2`. Last, print the places, joined with `", "`, as `Places: cafe, platform 2, ticket hall`. Copy your functions into this box first.

```python
register = {
    "A1": {"kind": "umbrella", "place": "platform 2"},
    "A2": {"kind": "phone", "place": "ticket hall"},
    "A3": {"kind": "umbrella", "place": "cafe"},
    "A4": {"kind": "scarf", "place": "platform 2"},
}
```

> Say it: a new item, then a ticket, go in; what comes out? ([How to start a problem](99-how-to-start-a-problem.html))
> Split it: ask for the kind and the place, and keep the register with the new item in it; ask for the ticket; if the register has it, print the claim line and keep the register without it; otherwise, print the no-item line; count the kinds, and print a line for each; print the places.
> Name it: the functions are named for you. What would you call the three answers, and the counts?
> Check it: try glove, cafe and A2: the phone goes, and so does the ticket hall, since nothing else was found there. Then the awkward ones: a ticket that is not there, like A9; `a1`, with a small a, which is not a key either; and A5, the new item's own ticket.
