 1. A string is a ____ of characters, so indexing and slicing work on it
    much like they do on a list.

      ANSWER: sequence

 2. Unlike a list, a string is ____-it cannot be changed after it is
    created, so every string method returns a new string instead of
    modifying it.

      ANSWER: immutable

 3. The ____ operator tests whether one string appears inside another, as
    in "quick" in sentence.

      ANSWER: in

 4. Sequences like \n and \t, which represent characters that can't be
    typed directly into a string, are called ____ sequences.

      ANSWER: escape
