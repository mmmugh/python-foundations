VOCABULARY

 1. A ____ function is one that calls itself, as long as it always calls
    itself on a smaller version of the problem and knows when to stop.

      ANSWER: recursive

 2. The ____ is a version of the problem small enough to answer outright,
    with no further call.

      ANSWER: base case

 3. The ____ calls the function again on a smaller input and builds the
    answer from the result.

      ANSWER: recursive case

 4. Recursion is not a loop that goes around; it is a ____ of unfinished
    work that unwinds.

      ANSWER: stack

 5. Remembering answers already computed, so they are never recalculated,
    is a technique called ____.

      ANSWER: memoization

 9. What does this print?

        def factorial_traced(n, depth=0):
            indent = "  " * depth
            print(f"{indent}factorial({n}) called")
        
            if n <= 1:
                print(f"{indent}base case, returning 1")
                return 1
        
            result = n * factorial_traced(n - 1, depth + 1)
            print(f"{indent}returning {n} * factorial({n - 1}) = {result}")
            return result
        
        
        factorial_traced(2)

      ANSWER: factorial(2) called
            factorial(1) called
            base case, returning 1
          returning 2 * factorial(1) = 2
